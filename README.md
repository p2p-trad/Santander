# Réplica Educativa: Portal Banco Santander (Particulares)

## 📌 Descripción
Este proyecto es una réplica simplificada y con fines **estrictamente educativos** de la página de inicio de "Particulares" del Banco Santander. El objetivo es proporcionar un ejemplo práctico de estructura semántica HTML5 y diseño básico con CSS3, basado en el contenido público del sitio web oficial.

## 📂 Estructura del Proyecto
- `index.html`: Contiene la estructura semántica (header, main, sections, footer) y los estilos CSS básicos integrados para replicar la identidad visual (colores corporativos, tipografía y maquetación en rejilla).
- `README.md`: Este archivo de documentación.

## 🚀 Cómo visualizarlo
1. Asegúrate de que ambos archivos (`index.html` y `README.md`) estén en la misma carpeta.
2. Haz doble clic en el archivo `index.html` o ábrelo con cualquier navegador web moderno (Chrome, Firefox, Edge, Safari).
3. No se requiere ningún servidor local, instalación de Node.js ni dependencias externas.

## 🛠️ Tecnologías utilizadas
- **HTML5**: Uso de etiquetas semánticas (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**: Flexbox y CSS Grid para la maquetación, variables CSS para los colores corporativos y diseño responsivo básico.

## ⚠️ Aviso Legal y Ético (Muy Importante)
- **Fines educativos**: Este código ha sido generado exclusivamente para aprender desarrollo web frontal (Frontend).
- **No es el sitio real**: No tiene funcionalidad bancaria real, no recoge datos y no se conecta a ningún servidor del Banco Santander.
- **Propiedad Intelectual**: Las marcas, logotipos y textos son propiedad del Banco Santander. Esta réplica no debe usarse para suplantar la identidad del banco (phishing), ni alojarse en un servidor público accesible en internet.
- **Uso responsable**: El autor de este código no se hace responsable del uso indebido que se le pueda dar.
